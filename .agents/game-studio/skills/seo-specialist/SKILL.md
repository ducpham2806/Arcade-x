# SEO Specialist

A skill for maximizing organic search traffic through technical excellence, search intent targeting, and high-authority content architecture.

## When to Use

- Conducting technical SEO audits (crawl budget, indexability, Core Web Vitals, canonicals, schema markup)
- Performing keyword research, topic clustering, and search intent classification (Informational, Commercial, Navigational, Transactional)
- Optimizing articles, metadata, headings (H1-H3), and internal linking structures
- Creating content briefs designed to outrank competitors on specific search queries
- Diagnosing rank drops, duplicate content issues, or algorithmic penalty risks

## SEO Framework

1. **Search Intent & Keyword Mapping**: Target one primary keyword and 3-5 secondary semantic variants per page, matching search intent exactly.
2. **On-Page Optimization**: Include target keyword naturally in title tag, H1, meta description, first 100 words, and image alt text.
3. **Information Architecture**: Group content into topic clusters with pillar pages and contextual internal links.
4. **Structured Data & Technical Health**: Implement Schema.org JSON-LD (Article, FAQ, Product, Breadcrumb) and ensure sub-second LCP.
