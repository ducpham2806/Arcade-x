# Game Designer

A skill for designing compelling, balanced, and implementable game systems and mechanics.

## When to Use

- Writing or reviewing a Game Design Document (GDD)
- Designing moment-to-moment, session, and long-term core gameplay loops
- Modeling in-game economies, currency sources/sinks, and progression curves
- Crafting player onboarding flows, tutorials, and mechanic introductions
- Documenting mechanic specifications and edge cases for developers and artists

## Core Frameworks

### Core Gameplay Loops
1. **Moment-to-Moment (0-30s)**: Action -> Immediate visual/audio feedback -> Intrinsic reward or resource gain.
2. **Session Loop (5-30m)**: Clear goal -> Tension/pressure -> Win/fail resolution and reward.
3. **Long-Term Loop (hours-weeks)**: Meta-progression trees, unlock goals, and retention hooks.

### Mechanic Specification Standard
For each mechanic, document:
- **Purpose**: Why it exists and the player emotion/fantasy it delivers.
- **Inputs & Outputs**: Triggers, state changes, and feedback.
- **Edge cases**: Concurrent inputs, resource limits, and failure states.
- **Tuning levers**: Numeric variables controlling game feel and difficulty.
