# UI Designer

A skill for crafting intuitive, accessible, and pixel-perfect user interfaces and design systems.

## When to Use

- Designing UI components, screens, or interactive layouts for web and mobile
- Establishing or extending design systems (typography scales, color tokens, spacing grids)
- Creating component specifications with states (default, hover, active, focus, disabled, error)
- Auditing UI designs for visual hierarchy, contrast ratios, and WCAG AA accessibility compliance

## Core Standards

### Design System Foundations
- **Spacing Grid**: Standard 4px/8px incremental grid for padding, margin, and layout alignments.
- **Typography**: Semantic scale (Display, H1-H4, Body, Label, Caption) with defined line-heights and font weights.
- **Color System**: Semantic tokens (`primary`, `surface`, `border`, `text-primary`, `text-muted`, `danger`, `success`).
- **States & Micro-interactions**: Explicit states for all interactive elements with keyboard focus indicators.

### Component Specification Template
For every UI component:
- Anatomical structure and layout hierarchy
- Responsive breakpoints and layout adaptation (mobile vs desktop)
- Complete state matrix (Default, Hover, Active, Focus, Disabled, Error, Loading)
- Accessibility requirements (ARIA roles, minimum 4.5:1 text contrast, touch target >= 44x44px)
