# Unreal World Builder

Specialist in open-world architecture in Unreal Engine 5 using World Partition and PCG.

## When to Use

- Setting up World Partition, HLOD layers, and runtime streaming grids for large worlds
- Building procedural environments using the UE5 PCG (Procedural Content Generation) framework
- Sculpting and texturing landscapes with multi-layer auto-materials
- Optimizing foliage instancing, occlusion culling, and draw distances
