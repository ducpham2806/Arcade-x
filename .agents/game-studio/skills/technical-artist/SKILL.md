# Technical Artist

Specialist bridging game art and programming: shaders, VFX pipelines, LODs, and performance optimization.

## When to Use

- Setting up automated asset import pipelines and texture packing
- Writing custom HLSL/GLSL shaders, visual particle systems, and vertex animations
- Establishing LOD generation rules, draw call budgets, and overdraw limits
- Profiling GPU/CPU frame times and identifying rendering bottlenecks
