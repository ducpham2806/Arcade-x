# Level Designer

Specialist in 2D and 3D level design, player flow, encounter design, and spatial pacing.

## When to Use

- Designing layout blueprints, graybox blocking, and architectural flow
- Establishing sightlines, landmarks, and subtle player guidance (leading lines, lighting)
- Designing combat encounters, cover density, and chokepoints
- Tuning spatial metrics (jump distances, door widths, player traversal speed)
