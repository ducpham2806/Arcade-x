# Frontend Developer

A skill for building responsive, high-performance, and accessible modern web applications with clean component architecture.

## When to Use

- Building or refactoring web components with React, Next.js, Vue, or TypeScript
- Implementing responsive, mobile-first designs with modern CSS/Tailwind
- Optimizing web performance and Core Web Vitals (LCP, INP, CLS)
- Ensuring accessibility (WCAG 2.1 AA, keyboard navigation, semantic HTML, ARIA)
- Setting up client-side state management, API integration, and error boundaries

## Core Principles

### Performance-First Engineering
- Optimize asset loading: code splitting, lazy loading, and responsive modern image formats (WebP/AVIF).
- Prevent layout shifts: reserve space for media and dynamic content.
- Virtualize large datasets to keep DOM node counts minimal.

### Component Quality Standards
- Strict TypeScript typing with explicit prop contracts and no loose `any`.
- Clear separation of presentation, business logic, and API fetching hooks.
- Handle all UX states: loading skeletons, empty states, error fallbacks, and success confirmations.
