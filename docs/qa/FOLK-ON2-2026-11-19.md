## Mở và thu hồi qua catalog

`supabase/migrations/20261119154045_folk_online_catalog.sql` thêm `folk_online_enabled` mặc định `false` trên `public.launcher_games`. `launcher_catalog()` đã trả nguyên hàng. Bản dựng đọc giá trị `true` từ hàng `published` vừa lấy qua RPC. Menu game tải lại khi mở, khi trình duyệt trở lại hoặc có mạng, và sau mỗi 5 phút khi menu đang hiện. Khi mất mạng hoặc lần tải thất bại, menu ẩn lựa chọn online. Các ván đang ở trong phòng tiếp tục theo đồng hồ của server.

Biến `VITE_FOLK_ONLINE=1` dành cho máy chủ Vite dev để kiểm staging chưa có bảng `launcher_games`. Bản dựng đóng gói dùng catalog. Công tắc quản lý lối vào từ menu. Auth và quyền phòng do Edge xử lý.

Sau khi hai game được duyệt, đối chiếu project đích, chức năng Edge, lịch hết giờ, commit đã triển khai và hai hàng catalog trước khi mở. Kiểm kết quả dưới đây trước khi thay đổi.

```sql
select id, status, access_model, supports_offline, folk_online_enabled
from public.launcher_games
where id in ('o-an-quan', 'nhay-lo-co');
```

Ví dụ cho Ô Ăn Quan. Dùng `nhay-lo-co` trong cùng câu lệnh để mở Nhảy Lò Cò riêng. Nếu thiếu hàng hoặc hàng chưa `published`, chuẩn bị hàng xuất bản theo quy trình catalog trước. Xác nhận truy vấn trả đúng một hàng đã bật, rồi mở game ở một phiên mới và kiểm game còn lại theo cấu hình hiện tại.

```sql
update public.launcher_games
set folk_online_enabled = true, updated_at = now()
where id = 'o-an-quan' and status = 'published'
returning id, status, supports_offline, folk_online_enabled;
```

Thu hồi cùng một game nếu tạo phòng, vào lại hoặc chấm lượt gặp sự cố. Tải lại trang hoặc mở lại menu game để xác nhận mục online đã ẩn và ván offline tiếp tục được.

```sql
update public.launcher_games
set folk_online_enabled = false, updated_at = now()
where id = 'o-an-quan'
returning id, status, supports_offline, folk_online_enabled;
```

## Bằng chứng

- PGlite áp toàn bộ migration. SQL xác nhận hai cờ mặc định tắt, RPC trả game được bật, thu hồi giữ quyền chơi offline và game ngoài Folk không thể dùng cờ này. Bộ luật, lưu và phòng Folk qua 21 ca. Bundle Edge khớp nguồn.
- Playwright Folk qua 15/15 (12 offline, 3 online). Ô Ăn Quan tự nối lại sau khi chặn mạng giữa lượt. Nhảy Lò Cò hoàn thành thảy, nhảy, nhặt Chàm và xây Nhà ở RTT 250 ms mô phỏng. Catalog thử bật mỗi game riêng, giữ phòng đang chơi khi thu hồi, và mở lại đúng save offline khi RPC mất kết nối.
- Bản production cục bộ qua hai lượt mở từ sảnh, bật rồi thu hồi từng game bằng RPC giả lập. Cờ dev có trong môi trường dựng, cả hai menu vẫn mặc định ẩn online cho tới khi catalog bật. Lint, build và bundle budget (298,0 kB JS ban đầu gzip) qua.
- Preview cổng 4335 qua smoke khách trên desktop và màn hình giả lập 390×844. Hai game mở menu và yêu cầu đăng nhập khi chọn tạo phòng. Đã xem ảnh runtime trong `test-results/folk-online/`.
- Connector staging trả Edge `folk-duel-room` v2 `ACTIVE`, bảng phòng hiện diện, cron đang bật và lần chạy gần nhất `succeeded`. Staging chưa có bảng `launcher_games`. Kết nối HTTP trực tiếp từ máy kiểm bị proxy từ chối ở bước CONNECT.
- Kiểm bổ sung `tests/ux/entry-flow.cjs` dừng vì fixture không giả lập `syncPolicy`. Checkout `aad7895` cho cùng lỗi. Hai ca mở game thực qua sảnh trong bản production đã qua.
- Phần nghiệm thu cần hai tài khoản staging do anh tự kiểm, thiết bị vật lý và độ trễ mạng thật. Các truy vấn bật và thu hồi ở trên là thao tác phát hành sau khi được duyệt.
