# Gói deploy ArcadeX

Gói mã nguồn và website mới nhất, bao gồm các cải tiến launcher, Supabase và các game tới Shikaku 20 bài học/daily/hint.

- [Toàn bộ app — ZIP](./ArcadeX-Full-App-2026-10-12.zip?raw=true)
- [Website build sẵn — ZIP](./ArcadeX-Website-2026-10-12.zip?raw=true)

Git pull nhánh `release/arcadex-full-2026-10-12` sẽ lấy mã nguồn cùng các ZIP này. Nếu xem trên GitHub, chọn file ZIP rồi Download raw file. Sau khi giải nén gói đầy đủ, mở `BAT-DAU-DEPLOY.md`. ZIP là snapshot ngày 12/10/2026; những thay đổi mã nguồn về sau cần tạo build/ZIP mới.

Xem `SHA256SUMS` để kiểm tra file. Không chứa khóa quản trị hoặc dữ liệu người dùng Supabase.
